输入一句你信以为真的话，它去知乎把这句话历年的讨论捞回来，按年份排成一个年轮 —— 一眼看出这个说法是哪一年成为共识的、什么时候开始转向的。

> 每一个常识，都曾经是少数派。

---

## 它解决什么

每个人脑子里都装着一批从没说出口的常识 —— 买房是最好的投资、读研一定比本科好找工作。它们大多不是我们自己想出来的，是某个年代被反复讲、讲成了默认设置。

而**没有人知道自己信的那句话，是哪一年的共识**。

现成的搜索只会告诉你「现在大家怎么说」。它把所有年份混在一起，你拿到的是一堆回答，不是一条时间线。

**事实可以查证，共识没有时间戳 —— 这是这个项目想补上的那一个维度。**

## 它是怎么工作的

```
静态前端  ──►  轻量服务端  ──►  知乎开放平台（真实数据）
                    └──►  大模型（只做判断与选择，不产出文本）
```

| 接口 | 干什么 |
|---|---|
| `GET /api/suggest?q=` | 输入推荐：只发**一条**搜索（约 0.8s）就返回 8 条真实高赞标题 |
| `GET /api/rings?q=` | 年轮数据：扇出 15 条查询 → 合并去重 → 按年分桶 → 抽句 |
| `GET /api/parse?q=` | 判断输入是断言/话题/疑问/垃圾（**只分类，不改写**） |
| `GET /api/picks?q=` | 在各年的候选句里挑一句（**只返回下标**） |
| `GET /api/health` | 部署自检 |

### 几个关键工程决策（都来自实测）

1. **一句话扇出成 15 条查询再合并去重。** 只发一条的话，知乎强烈偏向近期 —— 实测 49 条里 40 条落在当年，画出来是「今年的横截面」，不是年轮。
2. **正反两向都投。** 正向词 + 反向词（`{说法} 是错的`、`不认同 {说法}`）+ 年份探针，让同一年的支持与质疑都进池子。只留下说对的那几个，等于骗人。
3. **串行执行、撞限流立刻收手。** 实测限流卡的是**并发**（4 条并发 → 3 条被拒），不是串行速率（15 条零间隔串行全部成功）。去掉那个想当然的 1.2 秒间隔后，扇出从 28 秒降到 12 秒。
4. **AI 一律后台跑 + 落盘缓存 + 前端轮询。** 模型端点实测延迟在 3.5–286 秒之间剧烈抖动，绝不能挂在 HTTP 请求上等。
5. **AI 全是增强项。** 挂了页面照常能用，因为启发式结果早就在页面上了。

### 年轮几何：不调参，直接解

年份标签绕整圆均匀排开。难点是标签为横排两行字 —— 在上下两端吃掉的是它的高度、在左右两端吃掉的是它的宽度，差一倍多。所以逐年按它自己的角度算标签盒在半径方向的半投影，取最紧的那个当半径上限：

```
reach = 节点半径 + 间隙 + (|cosθ|·半宽 + |sinθ|·半高)
R ≤ (cx - margin - 半宽) / |cosθ| - reach
R ≤ (cy - margin - 半高) / |sinθ| - reach
```

**12 种视口实测通过**（1920 / 1600 / 1440 / 1280 / 1100 / 1024 / 768 / 390 / 360），判据是量实际渲染墨迹：字↔字、圆↔圆、字↔别家圆均无重叠，标签不出界。

## 设计原则：不编造，是硬约束不是风格偏好

凡是「看起来很像真的」的便利，一律让位给「能被核实」。这一条不只写在文案里，**它被写进了架构**。

- 年轮上的每一句话，都是**从知乎原文里整句抽出来的** —— 不生成、不改写、不拼接
- **接了大模型，但模型不产出任何要展示的文本。** 它只做两件事：判断输入形态，以及在已有的候选句里挑一句。**它返回的是下标** —— 句子本体是知乎原文，模型碰不到，所以**在架构上就不可能编造引语**
- 「换个说法再查」的候选，直接用语料里真实的高赞标题，不经过模型
- 立场（偏支持 / 偏质疑 / 两说）是**数关键词的启发式**，界面上明写「不作数」，不当统计结论卖

## 部署

全部走环境变量，都有默认值：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` / `PORT` | `127.0.0.1` / `8765` | 上线改成 `0.0.0.0` 和真实端口 |
| `ZHIHU_CLI` | 本机 kanshan-workbench 路径 | 换成你机器上的路径 |
| `AI_BASE_URL` | `https://api.openai-next.com/v1` | 任何 OpenAI 兼容端点 |
| `AI_MODEL` | `deepseek-v4-flash` | |
| `AI_API_KEY` | 无，读 `<项目根>/.ai_key` | **见下** |

### 密钥

密钥文件 `/.ai_key` **刻意放在项目根，不放 `nianlun-web/`** —— 因为 `server.py` 把 `nianlun-web/` 整个当静态根往外 serve，密钥放里面的话任何人访问 `http://站点/.ai_key` 就能拿走。

`server.py` 里另有一道兜底拦截：任何 `.` 开头的路径、`cache/`、`__pycache__/`，以及 `.py/.pyc/.mjs/.md` 后缀一律 404。

**上线时优先用环境变量注入，不要把密钥文件传上去。**

## 已知限制

- **实时检索 13–21 秒**，因为知乎接口单次约 0.76 秒、一次要找 15 条，且限流不允许并发。缓存命中时 0.06 秒
- **年轮上每年只出一句**。「一句话代表一整年」本身有语义跳跃，界面上如实标注为「当年 N 条里说得最直白的一句」+ 作者，而不是「那一年的观点」
- **立场判断是启发式**，会在若干年判错，界面上明写不作数
- **长尾话题的年份覆盖偏薄**，取决于知乎上实际的讨论量
